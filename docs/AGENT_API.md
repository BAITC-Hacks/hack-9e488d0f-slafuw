# EventMatch Agent v1: текущее приложение

## Запуск

Python 3.11+; внешних pip-зависимостей нет.

```bash
cp .env.example .env
python -m eventmatch serve
```

Windows PowerShell: `Copy-Item .env.example .env`, затем та же команда Python.
Откройте http://127.0.0.1:8000. Переменные процесса имеют приоритет над `.env`.
`.env` загружается относительно корня проекта; команды запускайте из корня.
Заполните локально `OPENAI_API_KEY` и `NVIDIA_API_KEY`. Ключи не нужны браузеру.
Идентификатор организации `org-…` не заменяет API key.

Без ключей работает структурированная форма. Свободный текст возвращает явную
ошибку доступности агента, а не выдуманные параметры. По умолчанию ранжирование —
`deterministic_baseline`. Это не использование NVIDIA.

## Включение обоих провайдеров

1. Настройте ключи в локальном `.env`.
2. Выполните `python -m tools.prepare_semantics`.
3. Только после успешной подготовки установите `EVENTMATCH_RANKER=nvidia`.
4. Запустите заново `python -m eventmatch serve`.
5. Отправьте заполненный запрос через блок диалога.

Подготовка делает реальные POST к `https://integrate.api.nvidia.com/v1/embeddings`:
модель `nvidia/llama-3.2-nv-embedqa-1b-v2`, `input_type=passage` для фрагментов и
`query` для канонических намерений, `encoding_format=float`, `truncate=NONE`.
Описания разбиваются на точные фрагменты не более 400 символов, с исходными offsets.
Ошибка API/слишком длинного ввода прерывает подготовку, не создавая ложного артефакта.

Русский входит в список языков оценки этой модели. Это не гарантия качества
на event-каталоге; сравнивайте объяснения на демонстрационных запросах.

`data/semantic/nvidia.json` содержит целочисленные cosine-оценки, модель, дату,
число успешных API-вызовов, checksum embeddings, каталога и всего артефакта.
Он не содержит ключей. Сохраните именно этот артефакт для воспроизводимого запуска.
Checksum проверяет целостность, но не является криптографическим доказательством
происхождения: используйте артефакты, подготовленные доверенным сервером команды.
Отсутствующий, несовместимый или изменённый артефакт в NVIDIA-режиме останавливает
запуск. Переключение в baseline возможно только явной настройкой с перезапуском.

Сортировка допустимых профилей:
`(-semantic_score_int, price_from_kzt, id)`, где score — максимальная сохранённая
оценка фрагмента относительно «категория + формат». Низкая оценка не исключает профиль.

OpenAI: `https://api.openai.com/v1/chat/completions`, модель по умолчанию
`gpt-4.1-mini-2025-04-14`, изменяется через `OPENAI_MODEL`.
Используется strict function calling. Модель извлекает заказ и выбирает источники,
backend определяет допуск, состав, порядок, статус, числа и финальный текст.

## Маршруты

| Метод и путь | Вход / результат |
|---|---|
| `GET /health` | Наличие каталога и режим ранжирования |
| `GET /metadata` | Города, категории, форматы, языки, календарь, версии |
| `POST /recommend` | Структурированный заказ → до трёх карточек, источники, result_id |
| `POST /chat` | `{ "message": "…", "session_id": null }` → результат или уточнение |
| `POST /compare-dates` | `{ "request": {...}, "date_a": "2026-10-12", "date_b": "2026-10-13" }` |
| `POST /finalize-result` | `{ "result_id": "…", "explanation_plan": { "cards": [...] } }` |

`Content-Type: application/json`; максимум 32768 байт. Для chat максимум 4000 символов.
Обязательные поля заказа: city, category, event_date, event_format, budget_kzt.
Необязательные: language и duration_hours (null = не заданы).
Город/категория вне metadata — ошибка валидации. Пустая пара допустимых города и
категории — `no_category_in_city`. Нарушение условий внутри существующей группы —
`no_match`. Некорректный запрос HTTP 422; недоступность сервиса/агента HTTP 503.
`needs_clarification` и бизнес-исходы HTTP 200; chat также может вернуть
`invalid_request` с HTTP 200, если не удалось проверить аргументы модели.

### Диалог

`session_id` из ответа передавайте с последующими сообщениями. Сервер хранит
структурированное состояние SQLite; браузер хранит только идентификатор в sessionStorage.
«А если на 13 октября?» сохраняет остальные поля и явно установленный год.
Без ранее заданного года агент должен уточнить его. Каталог не задаёт год по умолчанию.
Запрос «как подобрали?» возвращает сохранённые условия, фильтры, версии и основания.
При конкурирующих изменениях сессии действует проверка revision; повторите проигравший запрос.

### Проверка объяснений

Каждая карточка содержит `available_facts` и `available_evidence` с profile_id,
постоянными evidence_id и точными диапазонами исходного description.

```json
{
  "cards": [
    {
      "profile_id": "ID из текущего результата",
      "fact_ids": ["fact_id из этой карточки"],
      "evidence_id": "evidence_id из этой карточки"
    }
  ]
}
```

Нужно перечислить все карточки в исходном порядке, выбрать 1–3 факта и одну цитату.
Подмена ID, источника, добавление текста, удаление/перестановка карточек отклоняются.
Финализатор повторно проверяет допуск и актуальный top-3. Свободное рекламное
перефразирование не выводится. Цитаты маркируются как утверждения самого профиля.

### Сравнение дат

`results` содержит два полных результата; `appeared_ids`, `disappeared_ids` —
изменение показанного top-3. `changes` содержит допуск и причины по обеим датам.
`calendar_changed` означает изменение причины занятости; проверяйте также другие
reasons — освобождение даты не означает прохождение всех условий.
`top3_competition` означает допустимость на обеих датах и изменение места в top-3.

## Скорость, диагностирование, ограничения

Общий сетевой бюджет chat — 9 секунд по умолчанию (настраивается до 10).
При сбое выбора источников возвращается уже вычисленный top-3 с шаблонными
объяснениями. При сбое разбора нового сообщения предыдущая выдача не подставляется.
Ограничен параллелизм сетевых запросов; нет автоматических повторов и смены ranker.
Обработка HTTP и локальные операции добавляют небольшой overhead к сетевому deadline.

`metadata`: режим ranker, версия каталога/сервиса, NVIDIA artifact/online_calls=0,
фактическое использование OpenAI и режим объяснений. `agent_diagnostics`: реальные
этапы и длительность. `var/eventmatch.sqlite3`, таблица audit: структурированные
аргументы, допуск/причины, ID, выбранные источники и версии. Сырые сообщения,
API-заголовки и ключи не журналируются. Не вводите секреты в пользовательский чат.
Сессии и результаты хранятся до суток (максимум 2000 объектов), журнал — 5000 записей.

HTTP-сервер — локальный демосервис. Для публичного размещения нужны reverse proxy,
TLS, авторизация и ограничения запросов. По умолчанию слушает только localhost.
Docker Compose тоже публикует порт только на localhost:

```bash
docker compose up --build -d
```

Подготовьте NVIDIA-артефакт до сборки Docker, чтобы он попал в образ.
`.env` исключён из образа; секреты передаются контейнеру при запуске.

## Проверка

```bash
python -m unittest discover -s tests -v
python -m tools.check_repository
```

Unit-тесты провайдеров используют явно заданные фикстуры и не доказывают доступность
API-ключей. Исходные CLI-примеры/снимки продолжают проверять baseline v0.1;
`python -m eventmatch recommend` — прежний автономный baseline CLI.
Для текущего агентного/NVIDIA-режима используйте HTTP.

Live-проверка: подготовьте артефакт реальным NVIDIA API, затем выполните chat-запрос,
проверьте `metadata.nvidia.usage=prepared_artifact`, `metadata.openai.used=true` и
`explanation_mode=openai_source_selection_backend_render`.
