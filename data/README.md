# Данные

- `raw/hackathon-dataset-anonymized.jsonl` — 66 профилей, преобразованных из CSV организаторов.
- `manifest.json` — SHA-256 исходного CSV и канонического JSONL, точные преобразования.
- `reports/audit.json` — повторяемая статистика, `python -m tools.audit`.
- `reports/benchmark.json` — локальный измеренный результат, `python -m tools.benchmark`; время зависит от среды.

Подготовка не изменяет описания, цены, города, флаги и занятые даты по смыслу. Массивы CSV становятся JSON-массивами, `True`/`False` — boolean, пустые часы — null. Записи сортируются по ID.

53 профиля имеют `synthetic=false`, 13 — `synthetic=true`. Все относятся к исходному организаторскому набору; собственные профили команды не добавлены. UI явно помечает синтетику и значения `price_imputed`/`city_imputed`.

Оригинальный HTML не используется для подбора: он не содержит полных календарей. Приложение читает только включённый JSONL. Внешний исходный CSV нужен лишь для повторного импорта, а не для запуска.

При будущем добавлении профилей команды: сохранить исходный набор, завести отдельный файл добавлений и манифест происхождения по ID, установить `synthetic=true`, обновить загрузчик и метки. Не смешивать добавления с текущим организаторским набором без изменения версии и документации.
