# EventMatch · #79-lite

**До трёх event-подрядчиков с проверяемым объяснением выбора.**

Решение хакатон-трека «Умный подбор подрядчиков» для каталога Казахстана. Главная ценность — помочь сравнить допустимых кандидатов, объяснить различия и честно показать ограничения каталога.

В репозитории есть **работающий агент и детерминированный backend**: 66 исходных профилей, OpenAI function calling, подготовка NVIDIA embeddings, чат, сравнение дат, проверяемые объяснения, сохранённое состояние и журнал действий.

**Настройка двух провайдеров: [docs/PROVIDERS.md](docs/PROVIDERS.md).** OpenAI проверен живыми запросами с моделью `gpt-5.5`; готовый NVIDIA-артефакт не прилагается. Пока NVIDIA-ключ и артефакт не настроены, ранжирование остаётся явно обозначенным baseline.

## Запуск за минуту

Нужен **Python 3.11+**. Команды выполняются из корня проекта. Внешние Python-зависимости не нужны. Запуск без API-ключей даёт форму и детерминированный baseline; свободный текст требует OpenAI, семантическое ранжирование — подготовленный через NVIDIA артефакт.

```console
python -m eventmatch serve
```

Открыть **http://127.0.0.1:8000**. Кнопки над формой заполняют и выполняют реальные демозапросы. Остановка — `Ctrl+C`; другой порт — `python -m eventmatch serve --port 8080`.

Проверить без браузера:

```console
python -X utf8 -m tools.demo
python -X utf8 -m eventmatch recommend --request examples/01-dense.json
python -X utf8 -m unittest discover -s tests -v
python -X utf8 -m tools.check_repository
```

`-X utf8` удобен в Windows PowerShell для корректной кириллицы. Дата ограничена календарём **2026-09-23 — 2026-12-31**; для воспроизводимости демонстрация не зависит от сегодняшнего дня.

## Как устроен подбор

```text
Валидация запроса
  → город + точная категория: исходный круг кандидатов
  → календарь + бюджет + формат + язык + часы: жёсткие ограничения
  → устойчивое ранжирование допустимых
  → до 3 карточек: факты запроса + отличающая цитата из профиля
  → понятная сводка исключений + источники + версия данных
```

**Три явных исхода:**

- `matched` — есть от одного до трёх вариантов; объясняем, если их меньше трёх.
- `no_category_in_city` — в исходном каталоге города нет такой категории.
- `no_match` — категория в городе есть, но все кандидаты нарушают хотя бы одно условие.

Неверный запрос, например дата вне известного календаря, — отдельная ошибка валидации, HTTP 422.

### Что уже реализовано

- Загрузка и проверка типизированного JSONL, преобразованного из предоставленного CSV.
- Все обязательные входы, опциональные длительность и язык.
- Один механизм для людей, коллективов и площадок.
- Строгая проверка занятости, включая профили с `max_hours = null`.
- Устойчивый порядок: лексическая релевантность описания → стартовая цена → `id`.
- Два предложения объяснения с точной цитатой и координатами в исходном описании.
- Отдельные счётчики основных и всех причин исключения; причинная диагностика даты.
- Проверенные подсказки для пустой выдачи: ближайшая дата в пределах ±7 дней или минимальный достаточный бюджет, если достаточно изменить только его.
- Видимые метки синтетики и проставленных значений.
- Локальный HTTP API, форма, CLI, CI-конфигурация, тесты и снимки ответов.
- OpenAI Responses API: извлечение заказа, уточнения, function calling, выбор существующих оснований.
- NVIDIA Embeddings API: русскоязычные фрагменты и намерения, замороженные целочисленные оценки и SHA-256.
- `recommend`, `compare_dates`, `finalize_result`, metadata; проверка источников и сохранение top-3.
- SQLite: структурированное состояние диалога, результаты и журнал фактических вызовов.
- Чат, изменение одного условия, сравнение дат, вопрос «почему?», deadline и шаблонный fallback.

### Включить оба провайдера

После передачи `OPENAI_API_KEY` и `NVIDIA_API_KEY` в окружение сервера:

```powershell
python -X utf8 -m tools.prepare_semantics --output data/nvidia-artifact.json
# После успешной подготовки:
$env:EVENTMATCH_RANKER = 'nvidia'
python -X utf8 -m eventmatch serve
```

Режим фиксируется при старте. Ошибка NVIDIA-артефакта не переключает сервис незаметно на baseline. Реальные модели, ограничения API и диагностика описаны в [инструкции](docs/PROVIDERS.md).

## Данные и воспроизводимость

- 66 профилей, 17 категорий; Алматы — 50, Астана — 15, Зарубежье — 1.
- 53 профиля с `synthetic=false`, 13 синтетических профилей организаторов.
- Команда добавила **0** профилей. Поля и календари исходного CSV сохранены.
- Исходный JSONL-файл организаторов не был предоставлен в рабочей папке; включённый JSONL воспроизводимо получен из их CSV.
- Происхождение, преобразования и SHA-256 — [data/manifest.json](data/manifest.json).
- Цена «от» — нижняя граница за мероприятие; не расчёт окончательной сметы.
- `max_hours=null` — ограничение неприменимо, а не неизвестная или бесконечная длительность присутствия.

Пересчитать аудит и измерить скорость:

```console

python -X utf8 -m tools.benchmark
```

Для повторного импорта из исходного CSV:

```console

python -X utf8 -m tools.audit

```

Импорт перезаписывает канонический JSONL и манифест. Обычный запуск использует включённые данные и ничего скачивать не требует.

## Проверки и исходный benchmark

Тесты включают независимую проверку ограничений на всех 100 датах, детерминизм после перезапуска, чужие источники и выдуманные IDs, состояние заказа, неоднозначный год, сравнение дат и сбои API. Провайдерные тесты работают с тестовыми ответами; живые вызовы требуют настроенного серверного окружения.

Сохранённый замер: **350 вызовов ядра**, p50 **0,403 мс**, p95 **1,583 мс**, максимум **5,029 мс**. Это локальное время прогретого ядра, без HTTP, браузера и параллельной нагрузки; полный результат — [benchmark.json](data/reports/benchmark.json). Это не обещание production SLA.

HTTP-интеграция проверена тестами; визуальная проверка в браузере и слепая оценка полезности объяснений входят в предзащитный план. CI-файл подготовлен, удалённый запуск GitHub Actions здесь не выполнялся.

## Границы текущей версии

Лексические признаки и извлечение предложений не понимают отрицания и сложные смысловые связи. Источник цитаты доказывает наличие утверждения **в профиле**, а не независимую достоверность рекламы. У нас нет рейтингов качества, статистики успешных заказов, окончательных цен и сведений о свободных датах за пределами календаря.

Локальный сервер на стандартной библиотеке предназначен для живой демонстрации. Для публичного пилота план предусматривает FastAPI, формальный OpenAPI-контракт, наблюдаемость и версионирование данных.
